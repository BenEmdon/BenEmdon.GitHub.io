Code review for the agent era

October 2026

This series is about one thing: how we get to the next magnitude of agent scale.

Thesis

The pull request UI was built for humans reading diffs line by line. The review surface needs a rebuild around agents and intent. That rebuild is part of how we get to the next magnitude of agent scale.

Where we are

Our code review tool is a bet that the GitHub pull request UX is not the end state of code review. But a prettier diff is still a diff. Reviewers still scroll lines, still reconstruct intent from code, still approve changes they half-understood. We changed the surface; we have not changed the job.

The bet

Flip the review. The agent that wrote the change explains it first: what it intended, what it considered, what it ruled out. The AI reviewer runs on every change, always, and its findings are part of the change record. Humans review intent and consequence, not lines:

  • Is this the right change?
  • Does it do what it claims?
  • What is the blast radius, and what is the rollback story?

And the diff itself stops being text. Semantic diffs show what changed in meaning: behavior changes surfaced, mechanical changes collapsed. A rename across fifty files should read as one line, not fifty. A subtle behavior change buried in a large diff should be impossible to miss.

This closes the loop with the rest of the series. Solved source control gives every tool cheap, programmatic access to history and blame, so the review surface can answer “has this pattern caused incidents before” inline. Agent approvals give low-risk, well-understood changes a path that clears without a human in the loop. The review surface is where the remaining human judgment gets spent, and only there.

What we build

  1. A review surface where the authoring agent’s intent summary is the primary artifact and the code is secondary.
  2. Always-on AI first pass, with findings attached to the change record.
  3. Semantic diff views: behavior up, mechanics down.
  4. A tight loop into agent approvals: changes the system understands clear without waiting on a person.

Open questions

  • How much context a reviewer actually needs to judge intent, and how we keep the intent summary honest.
  • When a human must still read the code, and how the surface makes that call instead of the reviewer guessing.
  • Whether intent review composes across stacked changes, or whether stacks need their own review shape.
