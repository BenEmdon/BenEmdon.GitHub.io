$ notes

Notes on source control and code review at agent scale. One series so far, in six parts, written October 2026. It starts from a simple observation: the tools were designed for humans moving commits and reading diffs, and agents are about to move and read far more of both.

Subscribe: Atom feed. No comments; replies by email are welcome.

1 · Solving source control Every commit, landed or in flight, in one place: the commit cloud. 2 · Agent approvals Approvals become semantic policy plus intent review, not a flat human gate. 3 · Removing the merge queue Land fast, verify continuously, revert forward: the deploy gate is the real quality bar. 4 · Code review for the agent era Review intent and consequence, not lines: the diff stops being text. 5 · Merge-time code mods A code mod becomes a script the system runs inside the landing rebase, everywhere at once. 6 · Indexing the commit cloud Search and code intelligence computed at commit time, for every change, merged or not.
