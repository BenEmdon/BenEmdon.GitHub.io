$ about#

I lead two teams at Stripe: Code Forge and Code Review. Code Forge is the source control management every engineer touches daily, operating at the frontiers of Git scalability. Code Review builds the systems that drive higher quality and let engineers ship with confidence, with review speeds among the fastest in the industry.

Before Stripe I was at GitHub. I care about tools that feel fast and build confidence.

$ work#

2025 - to now Stripe: Engineering Manager

Leading Code Forge and Code Review at Stripe: 11 direct reports, plus 3 cross-appointed engineers, spanning source control management and AI-assisted code review.

2022 - to 2025 Stripe: Software Engineer

Pioneered stacked pull request tooling, so engineers work on dependent changes without blocking on review, and built an auto-merge system that cut time-to-production by over an hour per pull request company-wide. Built the centralized ownership infrastructure for code, service, and feature-flag ownership across every platform team, and led Stripe's Black Friday/Cyber Monday code freeze across 10+ infra teams.
