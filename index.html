$ about#

I lead two teams at Stripe: Code Forge and Code Review. Code Forge is the source control management every engineer touches daily, operating at the frontiers of Git scalability. Code Review builds the systems that drive higher quality and let engineers ship with confidence, with review speeds among the fastest in the industry.

Before Stripe I was at GitHub. I care about tools that feel fast and build confidence.
