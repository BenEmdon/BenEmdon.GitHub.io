$ about#

I am interested in the systems between writing code and safely shipping it. I like making large codebases feel fast, understandable, and easy to change.

At Stripe, I lead Code Forge and Code Review. We build source control infrastructure for Stripe's massive, fast-moving Git monorepo and improve the code review process, including an AI reviewer designed to catch problems before production and eventually approve lower-risk changes. Before Stripe, I was at GitHub.

Technical interests: version control systems, blob-storage-backed database design, agent harness development, and developer productivity.

Otherwise: pickleball, strategy games like Magic: The Gathering and Twilight Imperium, exploring cities near and far, and going max effort at karaoke.
