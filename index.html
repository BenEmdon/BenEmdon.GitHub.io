$ about#

I am interested in the systems between writing code and safely shipping it. I like making large codebases feel fast, understandable, and easy to change.

At Stripe, I lead Code Forge and Code Review. We build source control infrastructure for Stripe's massive, fast-moving Git monorepo and improve the code review process, including an AI reviewer designed to catch problems before production and approve changes in a high compliance environment. Before Stripe, I was at GitHub.

Technical interests: version control systems, blob-storage-backed database design, agent harness development, developer productivity, and "hill climbing".

Otherwise: racquet sports like badminton and pickleball, strategy games like Magic: The Gathering and Twilight Imperium, pixel art and old video games, exploring cities near and far, and going max effort at karaoke.
